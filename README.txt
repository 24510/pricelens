============================================================
 PriceLens · 价格透镜   v1.0.0
 本地优先的商品价格记录与历史比价工具
============================================================

一、这是什么
------------------------------------------------------------
把你关注商品的每一次价格记录下来，看清它的历史走势：
最低价、最高价、平均价、价格曲线，一眼判断"现在是不是好价"。
还能装一个浏览器小脚本，逛商品页时自动把价格记进来。

完全本地运行：数据只存在你自己的电脑上，不联网、不上传。


二、怎么启动
------------------------------------------------------------
【打包版】双击 PriceLens.exe
    （文件夹里还有 web\、config.example.ini、README.txt，勿拆散）

【开发模式】在项目目录执行：
    .venv\Scripts\python.exe src\main.py


三、界面速览
------------------------------------------------------------
· 顶栏   ＋ 添加商品 ／ 🔑 密钥设置 ／ 当前模式徽标
· 卡片   运行模式、监控商品数、价格记录数、采集端口
· 监控商品
    左侧列表   所有在监控的商品（平台、最近价、记录条数）
    右侧详情   统计五格（最近 / 最低 / 最高 / 平均 / 条数）
               价格走势曲线（可切 7天 / 30天 / 90天 / 全部）
               记价表单（价格 + 日期 + 备注）
               价格明细表（可逐条删除；最低价带「史低」标记）
· 一键记价   浏览器脚本：一键安装 / 生成 / 自检 / 重置令牌
· 导出 CSV   把全部价格记录导出成表格（Excel 可直接打开）
· 平台配置状态   每个平台当前是"本地"还是"增强"模式


四、数据存在哪   ★重要★
------------------------------------------------------------
全部数据集中在一个文件夹里：

    <程序目录>\PriceLensData\
        data\       数据库（pricelens.db，装着所有商品和价格）
        logs\       运行日志（密钥自动脱敏，可安全查看）
        config\     配置（config.ini，含密钥与令牌，切勿外传）
        userscript\ 一键记价脚本（含本机令牌，切勿外传）
        backups\    备份目录（预留）
        cache\      临时文件
        exports\    备用导出目录（仅当无法弹出保存对话框时使用）

· 备份 = 直接复制整个 PriceLensData 文件夹
· 迁移 = 把整个程序文件夹（含 PriceLensData）拷到新电脑，双击即用
· 卸载 = 删掉程序文件夹，不留任何残留


五、添加商品
------------------------------------------------------------
1. 在浏览器打开商品页，复制地址栏链接（拼多多 / 京东 / 淘宝 均可）
2. 程序里点「＋ 添加商品」→ 粘贴链接
3. 自动识别【平台】和【商品 ID】——看到绿色"✅ 已识别"即可
4. 填一个你认得出来的商品名称 → 保存
5. 在右侧详情里即可开始记价

识别不了时的两种情况：
· 短链接（如 m.tb.cn、3.cn）：先在浏览器打开它，再复制地址栏里的长链接
· 极少数特殊页面：展开弹窗里的「手动指定平台与 ID」自己填


六、记录价格（手动）
------------------------------------------------------------
在商品详情里填「价格」，选日期（默认今天），可加备注，点「记录价格」。
· 日期选今天   → 记录当前时刻
· 日期选其它天 → 记为当天 00:00:00（用于补录历史价）

备注示例：大促价、百亿补贴、券后、差价退款


七、一键记价（浏览器脚本）★推荐★
------------------------------------------------------------
在商品页右下角加一个小面板，把"当前价格"一键记进 PriceLens；
保持「自动记录」勾选时，逛商品页发现价格变化会自动入账，无需动手。

【安装（每台电脑一次）】
1. 浏览器安装扩展 Tampermonkey（篡改猴，Edge / Chrome 扩展商店可搜到）。
   装好后在扩展设置里开启「允许用户脚本」（新版浏览器必需）。
2. 回到本程序，点「一键安装 / 更新脚本」→ 浏览器弹出脚本安装页 → 点「安装」。
   （没弹安装页时：点「生成脚本」+「打开脚本文件夹」，
     把 pricelens.user.js 拖进浏览器窗口也能安装）

【使用】
· 打开商品详情页 → 右下角出现「📌 PriceLens 一键记价」小面板
· 新商品：点一次「记录」加入监控；已监控商品：价格变化时自动记录
· 价格没变化时不写记录（避免重复数据）；回到程序约 1 秒内自动刷新可见
· 小面板可点「—」收起；不想自动记录时取消勾选即可

【说明】
· 脚本内嵌仅属于本机的令牌，只能在你的电脑上读写你自己的 PriceLens
· 程序运行时占用两个本机端口：8765（界面）、8766（采集接口），
  均只监听 127.0.0.1，外部网络无法访问
· 脚本文件与 config.ini 请勿外传；万一泄露，点「重置令牌」并重新安装即可作废


八、密钥设置（可选 · 增强模式）
------------------------------------------------------------
不填密钥 = 本地模式，所有功能都能用（手动记价 + 浏览器脚本采集）
填密钥   = 该平台增强模式，P3 阶段将启用官方 API 自动刷新

填写位置：顶栏「🔑 密钥设置」→ 选平台填值 → 保存（即时生效）
· 界面只显示脱敏值（如 5027****a393）
· 日志中密钥自动替换为 ***
· config.ini 含密钥，请勿分享、上传、发给他人

各平台需要的字段：
  拼多多   client_id / client_secret / pid
  京东     app_key / app_secret / access_key / pid
  淘宝     无需密钥（用浏览器脚本采集）


九、数据目录的"逃生通道"
------------------------------------------------------------
程序默认把数据放在自己旁边的 PriceLensData。
若程序目录不可写（例如装在 C:\Program Files），会自动弹出
「需要选择数据存放位置」面板，让你另选一个位置。

手动更改：数据目录面板 →「更改数据位置…」
恢复默认：数据目录面板 →「恢复默认（程序目录）」

规则说明：
· 选磁盘根目录（如 D:\）时自动改用 D:\PriceLensData，避免数据散落
· 受系统保护的目录（如 C:\Program Files）和不可写目录会被拒绝
· 唯一记在外部的是一个一行路标文件：
      %LOCALAPPDATA%\PriceLens\location.txt
  （只为记住"你把数据放哪了"，不含任何隐私内容）

注意：更改数据位置后程序立即切换到新位置的数据库，
旧位置的数据不会自动搬过去（需手工复制整个 PriceLensData 文件夹）。

十一、日志与排错
------------------------------------------------------------
日志位置：PriceLensData\logs\pricelens-YYYY-MM-DD.log
· 用记事本打开（不要用 type 命令，会乱码）
· 日志中的密钥、令牌已替换为 ***

常见问题：
· 双击无反应 / 闪退
    检查 WebView2 运行时（Win10 1803+ / Win11 一般自带）
    缺失时安装微软官方 "WebView2 Runtime"
· 界面白屏
    关闭程序重开；仍不行查看当日日志
· exe 启动慢
    首次启动需初始化，等 3~10 秒属正常
· 商品页右下角没有「一键记价」小面板
    ① 浏览器扩展里确认 Tampermonkey 的脚本为"启用"
    ② 已开启「允许用户脚本」（或扩展页的"开发人员模式"）
    ③ 只对商品详情页生效（网址要带商品 ID）；刷新页面再试
· 浏览器点「一键安装 / 更新脚本」没弹安装页
    确认 Tampermonkey 已安装；仍不行改用「生成脚本 + 拖拽」方式
· 小面板显示「○ 未连接」
    PriceLens 没在运行（或采集接口未启动）；启动后刷新商品页
· 小面板提示「令牌不匹配」
    点过「重置令牌」后需重装脚本：程序里点「一键安装 / 更新脚本」
· 提示 8766 端口被占用
    打开 config\config.ini，把 [app] 段的 api_port 改成 8767 等值，
    重启程序后重新安装一次脚本
