  1. 浏览器装 Tampermonkey（篡改猴）扩展，并开启「允许用户脚本」
  2. 点「一键安装 / 更新脚本」→ 浏览器弹出安装页 → 点「安装」
  3. 打开任意商品页 → 右下角小面板点「记录」→ 回本程序 1 秒内出现
  4. 没弹安装页？点「生成脚本」+「打开脚本文件夹」，把 pricelens.user.js 拖进浏览器
